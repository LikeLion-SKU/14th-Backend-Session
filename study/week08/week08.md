# 1. 응답 통일
- 어플리케이션의 api가 클라이언트로 보내는 응답 형식을 일관되게 유지하는 작업
- 아래 3가지 요소가 필요함
  1. BaseResponse<T>
  2. Controller에서 응답 반환 시 BaseResponse.success() 방식 통일
  3. 예외 처리에서 응답 반환 시 BaseResponse.error() 방식 통일

# 2. 프로그래밍 오류
- 컴파일 에러: 컴파일 시 발생하는 에러
  - 컴파일 단계에서 발견되는 에러
  - 대표적으로 문법 구문 오류가 있음
- 런타임 에러: 실행 시에 발생하는 에러
  - 프로그램 실행 중에 발생하는 에러
  - 프로그래머가 역추적해서 원인을 확인해야함
  - 실행 도중 발생할 수 있는 런타임 에러를 고려해 대비해야함
- 논리적 에러: 실행은 되지만 의도와 다르게 동작하는 것
    - 버그의 일종
    - 프로그램이 실행하고 동작하는데 문제 없음
    - 의도와 다른 동작을 수행하여 서비스에 지장

# 3. 예외 처리
- `@RestControllerAdvice`: 모든 컨트롤러에서 발생하는 예외를 한 곳에서 처리할 수 있게 해주는 전역 예외 처리기. 클래스에 붙이며, 반환값을 자동으로 JSON 직렬화한다.
- `@ExceptionHandler`: 어떤 예외 클래스를 처리할지 지정하는 어노테이션. @RestControllerAdvice 클래스 안의 메서드에 붙이고, 인자로 넘긴 예외 타입이 발생하면 해당 메서드가 실행된다.

# 4. 유효성 검사 어노테이션
- `@NotNull`: 해당 필드에 null값 불가
- `@NotEmpty`: 해당 필드에 null, ""불가
- `@NotBlank`: 해당 필드에 null, "", " " 불가
- `@Min`: 해당 필드의 값이 최소값을 벗어나는지 검증
- `@Max`: 해당 필드의 값이 최대값을 벗어나는지 검증
- `@Size`: 문자열 최소, 최대 크기 검증, 숫자 최소, 최대값 검증
