로그 구성 & 구조

SLF4J (인터페이스)
-> 자바에서 로깅을 위한 인터페이스를 제공하는 라이브러리
로그를 직접 출력하지않고 구현체에만 전달만 함
인터페이스와 구현체를 분리하여 유연한 로깅

Logback(구현체)
SLF4J의 대표적인 로깅 구현체
실제 로그를 출력하는 역할

Facade 패턴
-> 여러 로깅 구현체를 하나의 인터페이스로 통합하는 중간 계층


로깅 라이브러리를 사용하는 이유
간단한 로그만 가능, 로그 레벨 구분 불가 로그 관리 어려움때문에 system.out.println을 사용 안함

로깅 라이브러리의 장점
1. 로그 레벨 설정 가능
2. 출력 형식 개발자가 원하는대로 지정 가능
3. 파일이나 데이터베이스에 저장 가능
4. 필터링 및 로그 관리 용이
5. 성능 향상
6. 스레드, 클래스 등 부가 정보 제공

로그 레벨
trace - 가장 상세한 로그
debug - 디버깅 정보
info - 일반적인 정상 흐름
warn - 경고, 서비스는 정상 동작
error - 오류 발생

개발 환경 -> debug / trace
운영 환경 -> info 이상

과도한 로그는 성능 저하 유발
