## JPA란?
- 자바에서 ORM 기술의 표으로 사용되는 인터페이스 모음
- 자바에서의 객체와 데이터베이스 사이의 테이블 매핑을 쉽게 해줌

## DTO 사용 이유
- 엔티티로 직접 데이터를 받거나 엔티티를 사용자에게 바로 반환하는 것은 굉장히 위험함.
- 또한 필요 없는 필드까지 사용되는 경우가 많기떄문에 필요없는 비용이 듦.

- -> 사용자에게 필요한 필드만 사용해서 데이터를 전송하자

## 트랜젝션이란?
- 데이터 거래에 있어서 안정성을 확보하는 방법
1. (Atomicity, 원자성): 하나의 트랜젝션은 원자적으로 처리되어야 함, 작업은 성공 or 실패 두가지만 가능
2. (Consistency, 일관성): 트랜젝션의 성공 유무와 관련없이 데이터의 상태는 일관되어야한다.
3. (Isolation, 격리성): 트랜젝션은 서로 독립적으로 실행되어야 하며, 동시에 실행되는 다른 트랜젝션이 영향을 미치지 않는다.
4. (Durability, 지속성): 트랜젝션의 완료 결과는 영구적으로 저장된다.

# 영속성 컨텍스트
- jpa의 사용 이유라고 생각함.
- 자체적인 성능 최적화가 일어남(불필요한 쿼리를 최소화 해줌)

## 영속성 컨텍스트의 중요 특징
1. 쓰기지연
- 엔티티를 저장(persist)하거나 수정해도 즉시 DB에 INSERT/UPDATE SQL을 보내지 않음
- 트랜젝션이 끝나는 타이밍에 자동 commit되며 이때 flush가 발동하여 db에 영구 저장.
2. 변경감지
- 별도의 매서드 호출이 없어도 엔티티의 수정 사항을 db에 저장.

3. 1차캐시
- 최초에 db에 접근하면 해당 데이터는 영속성 컨텍스트가 관리하게 됨.
- 이후 같은 데이터를 야러번 조회한다해도 insert 쿼리가 날아가지 않음. -> 성능 최적화
