Controller : 사용자에게 요청을 받고 service로직으로 넘기는거

JPA : 자바에서 orm 기술의 표준으로 사용되는 인터페이스 모음

Orm : 관계형 DB와 객체를 연결해주는 기술

JDBC VS JPA

JDBC
개발자가 직접 SQL 쿼리문 작성
유지보수가 어려움
반복성 코드 발생

JPA
객체를 통해 데이터 조작
복잡한 매핑 작업에 유리
유지보수 쉬움, CRUD 자동화

Service
@Transactional
-> 선언적 데이터베이스 트랜잭션 관리
public만 가능
같은 객체 내에서 호출 시 적용 안 됨

트랜잭션이란?
-> 데이터 거래에 있어서 안전성을 확보하기 위한 방법
ACID

선언 위치
클래스 vs 메소드
클래스 : 해당 클래스의 모든 public 메소드에 자동 적용됨

메소드 : 해당 메소드에만 적용, 구체적인 설정 가능

영속성 컨텍스트
-> 엔티티를 영구 저장하는 환경

*플러쉬
-> 영속성 컨텍스트의 변경 내용을 데이터베이스에 반영하는 것
