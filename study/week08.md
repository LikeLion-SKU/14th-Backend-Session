## 🫠 응답 통일

---

어플리케이션의 API가 클라이언트로 보내는 응답 형식을 일관되게 유지하는 작업

- 요소
    - BaseResponse<T>
    - BaseResponse.success()
    - BaseResponse.error()

## 🫠 프로그래밍 오류

---

- 프로그래밍에서 에러
    - 컴파일 에러 → IDE에서 에러 체크
    - 논리적 에러 → 코드와 알고리즘 체크
    - 런타임 에러 → 역추적해서 원인 확인

- 자바의 예외 클래스
    - `Error` 클래스 : 외부 요인으로 발생하는 오류 - 코드로 수습 불가 (ex 메모리 부족, 스택오버플로우)
    - `Exception` 클래스 : 수습될 수 있는 덜 심각한 오류(예외)  - 코드로 수습 가능 (ex 로직 실수, 특수한 사용자 상황)
        - 컴파일 예외 : IDE에서 체크 가능
        - (중요) 런타입 예외 : 개발자는 이 예외를 잘 체크해야 함!

## 🫠 예외 처리

---

- 로컬 예외 처리 : `try catch`문
- 전역 예외 처리 : `BaseErrorCode`, `CustomException,` `@RestControllerAdvice`

- 유효성 검사
    - Controller의 요청 본문 DTO에 `@Valid` 붙이기
    - DTO클래스에 제약 어노테이션 붙이기
        - `@NotNull` : 해당 필드에 null값 불가
        - `@Min` : 해당 필드의 값이 최소값을 벗어나는지 검증
        - `@NotEmpty` : 해당 필드에 null, “” 불가
        - `@Max` : 해당 필드의 값이 최대값을 벗어나는지 검증
        - `@NotBlank` :해당 필드에 null, “”, “ “ 불가 (최소 1글자)
        - `@Size` : 문자열 최소, 최대 크기 검증 숫자 최소, 최대값 검증

- 주의사항 : 예외처리를 남용하면 안된다
