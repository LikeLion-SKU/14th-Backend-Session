## 응답 통일이란?
- 응답 통일은 어플리케이션의 API가 클라이언트(프론트엔드나 외부 서비스)로 보내는 응답 형식을 일관되게 유지하는 작업
- 이를 통해 다양한 api를 호출하더라도 예상 가능한 json 형태로 응답을 받을 수있음

### 필요 요소
1. BaseResponse<T>: 공통 응답으로 활용할 클래스
2. BaseResponse.success(...): 성공 형식 통일
3. BaseResponse.error(...): 오류 형식 통일

## 프로그래밍 오류 3가지
1. 컴파일 에러: 컴파일 시에 발생하는 에러
2. 런타임 에러: 실행 시에 발생하는 에러
3. 논리적 에러: 실행은 되지만 의도와 다르게 동작

- 논리적 에러: 그냥 프로그래머가 코딩을 잘못해서 버그가 발생한것
- 컴파일 에러: 문법 오류 등으로 컴파일 자체가 안됨. IDE가 사전에 잡아줌
- 런타임 에러 (Runtime Error): 컴파일이 정상적으로 돌아가서 역추적해서 에러를 잡아야 함.

## 런타임 에러가 안나게 잡아야 함!!!

## 예외를 잡는 방법
1. try-catch: 한곳에서만 써야하거나 작은 부분에 대한 예외 처리, 간단한 부분에 사용
2. 전역 예외 처리: 구체적인 부분에 사용. 예외를 한 곳에서 처리하고, 응답 포맷을 통일함.

- 예외가 발생하면 해당 예외를 처리할수있는 handler가 잡아서 돌려줌
